ARCHITECTURE

├── required_tags: List[str]
└── optional_tags: List[str]

GenerationConfig
├── mode: GenerationMode
├── temperature: float
├── max_tokens: int

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Can't connect to Ollama
Solution: Run "ollama serve" and "ollama pull llama2"

Problem: Import errors
Solution: Run "pip install -r requirements.txt"

Problem: Validation failures
Solution: Lower temperature or increase retry_attempts in config

Problem: API errors
Solution: Check API key environment variables
